# 技术栈框架

技术栈：  Vue + element Plus + vue-router + vuex

样式： 语言使用scss, 响应式布局，rem单位+媒体查询

# vue文件

## 组件生成规范

- 1.编写组件时，要考虑结构通用性，对于公共部分优先使用element-ui组件库封装公共组件。
- 2.组件生成时，优先使用自定义的公共组件，其次使用element-ui组件库封装的组件，最后才考虑使用原生html标签封装
- 2.公共组件： 存放在src/components/common 目录下，用于封装公共的组件，如按钮、输入框、弹窗等。
- 3.业务组件， 存放在src/view/目录下，按业务划分文件夹生成。每个文件夹下包含index.vue文件，dialog弹窗文件夹，component组件文件夹。

## 样式引用规范

1. 新生成的vue文件的样式，样式语言优先使用scss, 样式嵌套优先编写，减少平铺编写 。
2. 必须引入rules.scss文件, 样式结构代码参考如下

```Vue
<style scoped lang="scss">
@use '@/assets/scss/rules' as *;
</style>
```

1. 样式编写：优先使用rules.scss定义各种mixin, 如颜色、 主题、 尺寸与布局 滚动条、文本处理、伪类 、字体样式 、搜索栏、 组件样式（弹窗、拉框、按钮、图标、卡片）字体大小、表格、动画与过渡等等。

2. 尺寸单位： 统一使用rules.scss定义pxToRem()函数转换
