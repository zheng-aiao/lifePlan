## 2. 组织结构

```
模块(M) → 页面(P) → UI组件(UC) → 功能(F)
```

### 2.1 ID命名规范

| 层级   | ID格式 | 示例       |
| ------ | ------ | ---------- |
| 模块   | Mxx    | M01, M02   |
| 页面   | Pxx    | P01, P02   |
| UI组件 | UCxx   | UC01, UC02 |
| 功能   | Fxx    | F01, F02   |

### 2.2 UI组件类型

| UI组件ID | 类型       | 说明             |
| -------- | ---------- | ---------------- |
| UC01     | 主页面区域 | 页面主要内容区域 |
| UC02     | 弹窗       | Modal弹窗        |
| UC03     | 抽屉       | Drawer抽屉       |
| UC04     | 对话框     | Dialog对话框     |
| UC05     | Tab页签    | Tab切换区域      |
| UC06     | 下拉面板   | Dropdown下拉面板 |
| UC07     | 其他       | 其他UI组件       |

### 2.3 功能类型

| 类型 | 定义     | 说明               |
| ---- | -------- | ------------------ |
| 查询 | 数据查询 | 查询、搜索、筛选等 |
| 新增 | 数据新增 | 新增、创建等       |
| 编辑 | 数据编辑 | 编辑、修改、更新等 |
| 删除 | 数据删除 | 删除、移除等       |
| 导入 | 数据导入 | 导入、批量导入等   |
| 导出 | 数据导出 | 导出、批量导出等   |
| 其他 | 其他功能 | 其他类型功能       |

## 3. 功能架构

### 3.1 功能树

```
项目名称
├── M01 [模块名称]
│   ├── P01 [页面名称] [/path]
│   │   ├── UC01 [UI组件名称] (主页面区域)
│   │   │   ├── F01 [功能名称] (查询)
│   │   │   │   ├── FP01 [功能点名称]
│   │   │   │   ├── FP02 [功能点名称]
│   │   │   │   └── FP03 [功能点名称]
│   │   │   └── F02 [功能名称] (删除)
│   │   │       └── FP04 [功能点名称]
│   │   ├── UC02 [UI组件名称] (弹窗)
│   │   │   ├── F03 [功能名称] (新增)
│   │   │   │   ├── FP05 [功能点名称]
│   │   │   │   └── FP06 [功能点名称]
│   │   │   └── F04 [功能名称] (编辑)
│   │   │       ├── FP07 [功能点名称]
│   │   │       ├── FP08 [功能点名称]
│   │   │       └── FP09 [功能点名称]
│   │   └── UC03 [UI组件名称] (抽屉)
│   └── P02 [页面名称] [/path]
│       └── UC04 [UI组件名称] (主页面区域)
│           └── F05 [功能名称] (查询)
│               └── FP10 [功能点名称]
└── M02 [模块名称]
    └── P03 [页面名称] [/path]
        └── UC05 [UI组件名称] (主页面区域)
            └── F06 [功能名称] (查询)
                └── FP11 [功能点名称]
```
