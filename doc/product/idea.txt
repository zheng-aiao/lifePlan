# 新建任务弹窗需求说明

## 一、功能概述

### 1.1 功能描述
用户可以通过新建任务弹窗创建不同类型的任务（年任务、月任务、日任务），实现对个人目标的多维度规划和管理。

### 1.2 使用场景
- 用户点击左侧导航栏"新增任务"按钮
- 用户在任务列表页面点击"新建"按钮

### 1.3 产品目标
- 提供统一的任务创建入口，降低用户操作成本
- 支持多维度任务规划，满足用户不同粒度的目标管理需求
- 通过任务层级关系，帮助用户拆解大目标为可执行的小任务

## 三、表单项详细说明

### 3.1 任务类型切换（Tab 选项卡）

**功能说明：**
- 提供三种任务类型选择：年任务、月任务、日任务
- 默认选中"日任务"（基于用户使用频率最高）
- 切换任务类型时，保留已填写的公共表单项数据
- 切换任务类型时，动态显示对应的"计划时间"表单项

**交互规则：**
- 点击 Tab 切换任务类型
- 选中状态高亮显示（建议使用品牌色）
- 切换时带有平滑过渡动画

---

### 3.2 公共表单项

#### 1. 任务标题（必填）

**字段规则：**
- 类型：单行文本输入
- 长度限制：1-50 个字符
- 必填项：是
- 占位符："请输入任务标题"

**交互说明：**
- 实时字数统计，显示在输入框右下角（格式：0/50）
- 获得焦点时显示边框高亮
- 失焦时触发验证：
  - 空值：显示错误提示"任务标题不能为空"，输入框变红
  - 超长：显示错误提示"任务标题不能超过 50 个字"
- 支持快捷键 Enter 提交（与确认按钮相同功能）

**验证规则：**
```
- 不能为空
- 不能纯空格
- 长度 1-50 字符
- 支持中文、英文、数字、常见标点符号
```

---

#### 2. 任务描述（选填）

**字段规则：**
- 类型：多行文本输入
- 长度限制：0-200 个字符
- 必填项：否
- 占位符："请输入任务描述（选填）"
- 默认行数：3 行

**交互说明：**
- 实时字数统计，显示在输入框右下角（格式：0/200）
- 支持自动扩展高度（最多 6 行，超出显示滚动条）
- 支持快捷键 Tab 缩进
- 失焦时触发验证（仅验证长度）

**验证规则：**
```
- 长度 0-200 字符
- 支持换行符
```

---

#### 3. 任务标签（选填）

**字段规则：**
- 类型：标签选择器（支持输入和选择）
- 数量限制：最多 5 个标签
- 必填项：否
- 默认值：无

**交互说明：**
- 点击"+ 添加标签"按钮打开标签选择器
- 支持从预设标签库中选择
- 支持自定义输入新标签（按 Enter 确认）
- 已选标签以 Tag 形式展示在输入框上方
- 点击 Tag 右侧"×"可删除标签
- 标签颜色根据任务类型自动匹配：
  - 年任务：蓝色系
  - 月任务：绿色系
  - 日任务：橙色系

**预设标签库示例：**
```
工作、学习、生活、健康、财务、社交、成长、其他
```

**验证规则：**
```
- 最多 5 个标签
- 单个标签长度 1-10 字符
- 不允许重复标签
```

---

#### 4. 优先级（必填）

**字段规则：**
- 类型：单选框组（Radio Button Group）
- 选项：高、中、低
- 必填项：是
- 默认值：中

**交互说明：**
- 水平排列三个选项
- 选中项高亮显示（建议使用颜色区分）：
  - 高：红色 (#F56C6C)
  - 中：橙色 (#E6A23C)
  - 低：绿色 (#67C23A)
- 点击选项即可切换
- 必选验证：提交时未选择则提示"请选择任务优先级"

**业务规则：**
- 优先级影响任务排序（高优先级任务排在前面）
- 优先级影响任务提醒策略（高优先级任务提前多次提醒）

---

#### 5. 计划时间（必填）

**字段规则：**
- 类型：根据任务类型动态变化
- 必填项：是

**分类型规则：**

##### 年任务
- 显示：年份选择器（如：2026）
- 格式：YYYY
- 默认值：当前年份
- 可选范围：当前年份前后 10 年
- 示例：2026

##### 月任务
- 显示：日期范围选择器
- 格式：YYYY/M/D - YYYY/M/D
- 默认值：当前月份的第一天到最后一天
- 示例：2026/3/1 - 2026/3/31
- 限制：
  - 开始日期 ≤ 结束日期
  - 时间跨度最多 31 天
  - 不能选择过去的日期

##### 日任务
- 显示：时间范围选择器
- 格式：HH:MM - HH:MM
- 默认值：当前时间的下一个整点小时
- 示例：15:30 - 16:00
- 限制：
  - 开始时间 ≤ 结束时间
  - 时间跨度最多 24 小时
  - 最小时间单位：5 分钟

**交互说明：**
- 点击输入框弹出时间选择器
- 支持快捷选择：
  - 年任务：今年、明年
  - 月任务：本月、下月
  - 日任务：今天上午、今天下午、今天晚上
- 选择器支持键盘操作（方向键选择，Enter 确认，Esc 取消）

**验证规则：**
```
- 不能为空
- 开始时间必须小于结束时间
- 不能选择过去的日期/时间（年任务除外）
```

---

#### 6. 父任务（选填）

**字段规则：**
- 类型：下拉选择器（支持搜索）
- 必填项：否
- 默认值：无
- 数据源：当前用户已创建且未完成的任务列表

**交互说明：**
- 点击输入框弹出下拉列表
- 支持输入关键词搜索任务
- 下拉列表显示任务标题和任务类型图标
- 支持清空已选父任务（点击"×"按钮）
- 不能选择自身作为父任务（如果编辑已有任务）
- 不能选择子任务作为父任务（避免循环引用）

**展示规则：**
```
下拉列表项格式：
[任务类型图标] 任务标题 (任务类型)
示例：
📅 年度学习计划 (年任务)
📆 3 月阅读计划 (月任务)
 今天晨跑 (日任务)
```

**业务规则：**
- 父任务用于任务拆解和层级管理
- 子任务继承父任务的部分属性（如标签）
- 父任务进度 = 所有子任务完成度的平均值
- 删除父任务时，子任务不会被删除，父任务关系清空

## 四、按钮说明

### 4.1 取消按钮

**样式：** 次级按钮（灰色边框）
**文案：** "取消"
**交互：**
- 点击后关闭弹窗
- 不保存任何数据
- 如果有已填写内容，不提示确认（避免打扰用户）
- 支持快捷键 Esc

---

### 4.2 确认按钮

**样式：** 主要按钮（品牌色填充）
**文案：** "确认"
**交互：**
- 点击后触发表单验证
- 验证通过：
  - 显示 loading 状态（按钮禁用，显示加载图标）
  - 提交数据到后端
  - 成功后关闭弹窗
  - 刷新任务列表
  - 显示成功提示 Toast："任务创建成功"
- 验证失败：
  - 高亮第一个错误字段
  - 显示错误提示
  - 按钮恢复可用状态

**异常处理：**
| 异常场景 | 处理方式 | 提示文案 |
|---------|---------|---------|
| 网络请求失败 | 保留表单数据，按钮恢复 | "网络异常，请重试" |
| 服务器错误 | 保留表单数据，按钮恢复 | "服务器繁忙，请稍后重试" |
| 重复提交 | 前端防抖，忽略重复点击 | 无 |
| 数据验证失败 | 阻止提交，高亮错误项 | 具体错误提示 |

## 五、业务流程

### 5.1 正常流程（Happy Path）

```mermaid
graph TD
    A[用户点击新建任务按钮] --> B[打开新建任务弹窗]
    B --> C[选择任务类型]
    C --> D[填写任务标题]
    D --> E[填写其他信息]
    E --> F[点击确认按钮]
    F --> G{表单验证}
    G -->|通过 | H[提交数据]
    H --> I[保存成功]
    I --> J[关闭弹窗]
    J --> K[刷新任务列表]
    K --> L[显示成功提示]
    G -->|失败 | M[显示错误提示]
    M --> E
```

### 5.2 异常流程

**异常 1：网络中断**
- 触发时机：提交数据时检测到网络中断
- 处理方式：保留表单数据，按钮恢复可用
- 提示文案："网络已断开，请检查网络连接后重试"

**异常 2：服务器错误**
- 触发时机：接口返回 5xx 错误
- 处理方式：保留表单数据，按钮恢复可用
- 提示文案："服务器繁忙，请稍后重试"

**异常 3：数据验证失败**
- 触发时机：用户点击确认按钮
- 处理方式：阻止提交，滚动到第一个错误字段
- 提示文案：具体字段错误提示

**异常 4：重复提交**
- 触发时机：快速多次点击确认按钮
- 处理方式：前端防抖，只响应第一次点击
- 提示文案：无（按钮显示 loading 状态）

## 六、数据埋点

| 事件名称 | 事件 ID | 触发时机 | 埋点参数 |
|---------|--------|---------|---------|
| 点击新建任务按钮 | click_new_task | 用户点击新建任务按钮 | 来源位置（导航栏/列表页/快捷键） |
| 打开新建任务弹窗 | open_new_dialog | 弹窗成功打开 | 无 |
| 切换任务类型 | switch_task_type | 用户切换任务类型 Tab | 当前选中的任务类型 |
| 填写任务标题 | input_task_title | 任务标题输入框失焦 | 输入长度 |
| 选择优先级 | select_priority | 用户选择优先级 | 优先级（高/中/低） |
| 选择计划时间 | select_plan_time | 用户完成时间选择 | 任务类型、时间跨度 |
| 添加任务标签 | add_task_tag | 用户添加任务标签 | 标签数量、是否自定义 |
| 选择父任务 | select_parent_task | 用户选择父任务 | 是否有父任务 |
| 提交新建任务 | submit_new_task | 用户点击确认按钮 | 任务类型、填写完整度 |
| 新建任务成功 | task_created | 任务创建成功 | 任务 ID、任务类型、优先级 |
| 新建任务失败 | task_create_failed | 任务创建失败 | 失败原因、任务类型 |
| 取消新建任务 | cancel_new_task | 用户点击取消按钮或关闭弹窗 | 已填写字段数 |

## 九、附录

### 9.1 字段数据结构

```json
{
  "taskType": "year|month|day",
  "title": "string(1-50)",
  "description": "string(0-200)",
  "tags": ["string"],
  "priority": "high|medium|low",
  "planTime": {
    "year": "number",
    "month": {
      "startDate": "date",
      "endDate": "date"
    },
    "day": {
      "startTime": "time",
      "endTime": "time"
    }
  },
  "parentTaskId": "string|null"
}
```

### 9.2 错误码说明

| 错误码 | 错误信息 | 处理建议 |
|-------|---------|---------|
| 400 | 请求参数错误 | 检查表单验证逻辑 |
| 401 | 未登录 | 跳转登录页 |
| 403 | 无权限 | 提示用户无创建权限 |
| 409 | 任务已存在 | 提示用户任务重复 |
| 500 | 服务器错误 | 提示用户稍后重试 |
| 503 | 服务不可用 | 提示用户稍后重试 |
