# 新增任务功能设计文档

## 功能概述

新增任务功能是LifePlan应用的核心功能之一，用户可以通过该功能创建不同类型的任务（年度任务、月度任务、日任务），实现对个人目标的全方位规划和管理。

---

## 任务类型定义

根据后端数据结构设计，任务类型（taskType）分为以下四种：

| 类型值 | 类型名称 | 说明 | 时间维度 |
|--------|----------|------|----------|
| 1 | 年度任务 | 长期目标，跨度为一年 | 年度级别，如"2026年" |
| 2 | 月度任务 | 中期目标，跨度为一月 | 月度级别，如"4月" |
| 3 | 日任务 | 短期目标，具体到某一天 | 日级别，精确到时间段 |
| 4 | 延时任务 | 延期处理的任务 | 从原任务延时产生 |

---

## 系统逻辑分析

### 1. 任务层级关系

```
年度任务 (taskType=1)
    ├── 可拆分为多个月度任务 (parentId关联)
    │       ├── 可拆分为多个日任务 (parentId关联)
    │       │       ├── 可产生延时任务 (taskType=4)
    │       │       └── 可包含多个子任务 (subTaskGroup关联)
    │       └── 可包含多个子任务
    └── 可包含多个子任务
```

### 2. 任务创建流程

```
用户点击新增按钮
    ↓
弹出新增任务弹窗
    ↓
选择任务类型
    ↓
根据类型展示对应表单字段
    ↓
填写任务信息
    ↓
[可选] 添加子任务
    ↓
[可选] 关联父任务
    ↓
提交创建请求
    ↓
后端验证并创建任务
    ↓
返回创建结果
    ↓
更新前端任务列表
```

### 3. 任务状态流转

```
创建任务 → 待开始(0)
    ↓
开始任务 → 进行中(1)
    ↓
    ├── 暂停任务 → 暂停中(2) → 恢复任务 → 进行中(1)
    ├── 完成任务 → 已完成(3)
    ├── 放弃任务 → 未完成(4)
    └── 延时任务 → 产生延时任务(taskType=4)
```

## 表单字段设计

### 通用字段（所有任务类型必填）

| 字段名 | 字段类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| title | 文本输入 | 必填 | 任务标题，最大200字符 |
| taskType | 单选按钮 | 必填 | 任务类型，默认选中"日任务" |
| category | 下拉选择 | 可选 | 任务分类：工作/学习/健身/生活 |
| taskPriority | 下拉选择 | 可选 | 优先级：低(1)/中(2)/高(3)，默认中 |
| description | 多行文本 | 可选 | 任务描述 |

### 年度任务特有字段

| 字段名 | 字段类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| year | 下拉选择 | 必填 | 选择年份，如2026年 |
| plannedStartTime | 日期选择 | 可选 | 计划开始日期（年度第一天默认） |
| plannedEndTime | 日期选择 | 可选 | 计划结束日期（年度最后一天默认） |

### 月度任务特有字段

| 字段名 | 字段类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| year | 下拉选择 | 必填 | 选择年份 |
| month | 下拉选择 | 必填 | 选择月份（1-12月） |
| plannedStartTime | 日期选择 | 可选 | 计划开始日期（月初默认） |
| plannedEndTime | 日期选择 | 可选 | 计划结束日期（月末默认） |
| parentId | 下拉选择 | 可选 | 关联年度任务（父任务） |

### 日任务特有字段

| 字段名 | 字段类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| date | 日期选择 | 必填 | 选择日期 |
| startTime | 时间选择 | 必填 | 开始时间（如07:00） |
| endTime | 时间选择 | 必填 | 结束时间（如09:30） |
| plannedStartTime | 日期时间 | 自动生成 | 根据date+startTime生成 |
| plannedEndTime | 日期时间 | 自动生成 | 根据date+endTime生成 |
| parentId | 下拉选择 | 可选 | 关联月度任务或年度任务（父任务） |

### 子任务字段

| 字段名 | 字段类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| title | 文本输入 | 必填 | 子任务标题 |
| priority | 下拉选择 | 可选 | 子任务优先级 |

## 交互设计

### 1. 任务类型切换

- 用户点击任务类型选项卡，表单动态切换显示对应字段
- 切换时保留已填写的通用字段内容
- 时间设置区域根据类型自动调整

### 2. 父任务关联

- 选择父任务时，下拉列表只显示对应类型的任务
  - 月度任务：只能关联年度任务
  - 日任务：可关联月度任务或年度任务
- 选择父任务后，自动继承父任务的分类和优先级（可修改）

### 3. 子任务添加

- 点击"添加子任务"按钮，新增一行子任务输入
- 子任务可拖拽排序
- 每个子任务可单独设置优先级
- 子任务数量上限：20个

### 4. 表单验证

| 验证项 | 验证规则 | 错误提示 |
|--------|----------|----------|
| 任务标题 | 必填，最大200字符 | "任务标题不能为空" / "标题长度不能超过200字符" |
| 任务类型 | 必填 | "请选择任务类型" |
| 开始时间 | 必填（日任务） | "请选择开始时间" |
| 结束时间 | 必填（日任务），必须大于开始时间 | "请选择结束时间" / "结束时间必须大于开始时间" |
| 子任务标题 | 必填 | "子任务标题不能为空" |

## API接口设计

### 创建任务接口

**请求**
```
POST /api/tasks
Content-Type: application/json
```

**请求体**
```json
{
  "title": "完成品牌设计规范指南",
  "description": "制定完整的品牌视觉规范文档",
  "category": "工作",
  "taskType": 1,
  "taskPriority": 3,
  "taskGroup": "",
  "plannedStartTime": "2026-01-01T00:00:00",
  "plannedEndTime": "2026-12-31T23:59:59",
  "parentId": null,
  "subTaskGroup": ""
}
```

**响应**
```json
{
  "code": 200,
  "message": "创建成功",
  "data": {
    "task_id": 123,
    "title": "完成品牌设计规范指南",
    "task_status": 0,
    "created_at": "2026-04-01T10:30:00"
  }
}
```

### 创建子任务接口

**请求**
```
POST /api/subtasks
Content-Type: application/json
```

**请求体**
```json
{
  "subTaskGroup": "uuid-xxx",
  "title": "色彩心理学研究",
  "sortOrder": 1
}
```

**响应**
```json
{
  "code": 200,
  "message": "创建成功",
  "data": {
    "subtask_id": 456,
    "title": "色彩心理学研究",
    "status": 0
  }
}
```

## 数据流设计

### 1. 创建任务数据流

```

    ↓

    ↓

    ↓

    ↓

    ↓

    ↓

```

```javascript
const formData = {
```

## 业务规则

### 1. 任务时间规则

| 任务类型 | 时间规则 |
|----------|----------|
| 年度任务 | 默认开始时间为年初，结束时间为年末 |
| 月度任务 | 默认开始时间为月初，结束时间为月末 |
| 日任务 | 时间范围限制在07:00-23:00，最小时长30分钟 |

### 2. 父任务关联规则

- 年度任务不能有父任务
- 月度任务只能关联年度任务作为父任务
- 日任务可关联月度任务或年度任务
- 延时任务自动关联原任务

### 3. 子任务规则

- 子任务通过 subTaskGroup 字段关联主任务
- 创建任务时自动生成 subTaskGroup UUID
- 子任务状态独立管理，不影响主任务状态
- 子任务全部完成时，可触发主任务进度更新

### 4. 任务组规则

- 同一任务组内的任务共享 taskGroup 标识
- 任务组用于归类相关任务，便于批量管理
- 创建时可选择加入已有任务组或创建新组

## 异常处理

### 1. 创建失败场景

| 场景 | 处理方式 |
|------|----------|
| 标题重复 | 提示"任务标题已存在，请修改" |
| 时间冲突 | 提示"该时间段已有其他任务安排" |
| 网络错误 | 提示"网络异常，请稍后重试" |
| 后端验证失败 | 显示具体验证错误信息 |

### 2. 数据校验

- 前端提交前进行基础校验
- 后端进行完整业务校验
- 双重校验确保数据完整性
